## A: Visualising the classification in single-model single-band rasters or multi-model multi-band rasters 

Each band of these rasters contain all classes of a model. So, a single map containing all the classes in that model can be made.

Visualise single-model single-band or multi-model multi-band images as single model maps in QGIS:

<br>

**Step 1:** Open all the tiles in the outputs in QGIS.

<br>

**Step 2:** Under 'Layers', select the top tile 

<img width="900" height="450" alt="image" src="https://github.com/user-attachments/assets/0bad21bf-61d8-4934-be76-fc727c6b32a9" />

**Step 3:** Scroll down to the last tile and then press Shift. This will select all the tiles loaded.

<img width="400" height="400" alt="image" src="https://github.com/user-attachments/assets/2abb6e61-2829-458d-bebc-beff14f4a0f7" />

**Step 4:** Press the 'Collapse All' button. 

<img width="400" height="400" alt="image" src="https://github.com/user-attachments/assets/f04ad76c-77d3-46a7-8e8d-f1357f61e9bd" />

**Step 5:** Then press the 'Add Group' button. Optional: Name the group if you want.

<img width="400" height="400" alt="image" src="https://github.com/user-attachments/assets/e07f6dad-f057-4632-b264-bd069a93ac4f" />

**Step 6:** 
```
Select one tile in the group> Right-click> Click on Properties...
```
<br>

**Step 7:** 
```
Symbology> change from Multiband Color to Paletted/Unique values
```

**Step 8:**

Select a band corresponding to the model which needs to be looked at:

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/870e48c0-4ecd-4174-8522-a79cf26d76b8" /> <br>

**Step 9:** Select a colour scheme in the color ramp (you can create a custom one too, like I have made):

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/b4d20232-9dd7-4223-a9d1-788defad0ebd" />

**Step 10:** Select 'Mode' as 'Equal Interval':

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/e1ad3e36-f2e2-4edb-96a9-d1e2ac229533" />

**Step 11:** Change the number of classes to the maximum number of classes possible in a model (corresponding to the custom colour ramp, if you have made one):

<img width="600" height="400" alt="image" src="https://github.com/user-attachments/assets/da92b9cc-205c-4c51-835d-ace983222481" /> <br>

**Step 12:** Click on 'Apply' (bottom-right) and then 'Ok'.

**Step 13:** 

```
Right click on that layer > Styles > Copy styles
```
<img width="650" height="450" alt="image" src="https://github.com/user-attachments/assets/b9a8e9d4-898f-42dc-ad33-990327726b42" /> <br>

**Step 14:** 

Paste the copied style on the group:

<img width="400" height="400" alt="image" src="https://github.com/user-attachments/assets/25fb4b2c-79a7-4c42-a6b9-44441af946be" />

This will result in the application of desired colour for each class on all the tiles:

## B: Visualising the classification in multi-band single-model rasters

Each band of these multi-band rasters are a single class. So, each class can be displayed individually as binary maps (present/absent).

Visualise multi-band images as single bands in QGIS:

<br>

Step 1 to Step 2 is the same as in section A. After that, follow these steps:

**Step 8:** Select a band corresponding to the land use class which needs to be looked at:

![enter image description here][2]

<br>

**Step 9:** Select a colour scheme in the color ramp:

![enter image description here][3]

<br>

**Step 10:** Press Classify and you get this:

![enter image description here][4]

<br>

**Step 11:** Press `Apply` on the tab from the previous step.

<br>

**Step 12:**
```
Right click on that layer > Styles > Copy styles
```
![enter image description here][5]

<br>

**Step 13:** 
Press shift and select the first and last tile (to select all the tiles at once) and paste style to the final map.

![enter image description here][6]

<br>

It will look like the following (ignore the missing chunk. This is from one of the earliest iterations). This is a binary map (presence = yellow; absence = dark blue) of dense forests. 

![enter image description here][7]

Raster > Miscellaneous > Merge
